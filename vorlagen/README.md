# Startpaket Wochenpaket

Gekürzte, fachneutrale Vorlagen zum Nachbauen. Die Originale aus dem Mathematik- und Physikunterricht sind länger und an die eigenen Klassen angepasst. Diese Fassungen sind der Kern, den ihr für euer Fach erweitert.

| Datei | Wofür |
|---|---|
| `CLAUDE.md` | Hausregeln für jede Sitzung: Sprache, Ordner, Upload nur nach Ok |
| `.claude/skills/wochenpaket/SKILL.md` | Der Ablauf: schneiden, zwei Agenten, prüfen, Lektorat, Upload |
| `.claude/skills/lerneinheit-vorbereiten/SKILL.md` | Macht aus einer Woche des Skripts eine ausführliche Lerneinheit |
| `.claude/skills/lernseite/SKILL.md` | Einstiegsfassung der interaktiven Lernseite |
| `.claude/skills/aufgabenblatt/SKILL.md` | Aufgabenblatt mit Operatoren, Anforderungsbereichen und Erwartungshorizont |
| `.claude/agents/autor.md` | Subagent, der das Material erstellt (Opus) |
| `.claude/agents/lektor.md` | Subagent, der die Sprache prüft (Sonnet) |
| `_werkzeuge/schnitt.py` | Schneidet das Halbjahresskript auf eine Woche zu |
| `KLASSE/quellen/halbjahresskript_vorlage.md` | Beispiel für das Format des Skripts (Biologie) |
| `KLASSE/kurs.json` | Kursdaten der Klasse (bleibt privat) |
| `erster-auftrag.md` | Text für die erste Sitzung: Claude richtet den Rest ein |

Der Ordner `.claude` beginnt mit einem Punkt und ist deshalb auf manchen Rechnern versteckt. Am einfachsten lasst ihr Claude die Dateien kopieren (siehe `erster-auftrag.md`).
