# KI-Unterrichtspakete

Wie Claude Code aus einem Halbjahresskript jede Woche Lernmaterial baut: eine interaktive Lernseite, ein Lernblatt mit Lösung, ein Aufgabenblatt und eine Unterrichtsplanung. Erklärt für Neugierige und als Bauanleitung für Kollegen, auch für andere Fächer.

**Zur Anleitung:** https://timonnetzel.github.io/ki_unterrichtspakete/
(oder `index.html` herunterladen und im Browser öffnen, sie läuft auch offline)

## Inhalt
- `index.html`: die interaktive Anleitung (Umschalter „Einfach“ und „Ausführlich“)
- `img/`: Screenshots echter Ergebnisse aus der Klasse 11BC
- `vorlagen/`: Startpaket zum Nachbauen (CLAUDE.md, Skills, Agenten, `schnitt.py`, Beispielskript)

## Beispiele im Einsatz
- 11BC Mathematik: https://github.com/TimonNetzel/11BC_Mathematik
- 13NF Physiktechnik: https://github.com/TimonNetzel/13NF_Physiktechnik_v2
